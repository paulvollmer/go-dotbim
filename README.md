# go-dotbim

[![CI](https://github.com/paulvollmer/go-dotbim/actions/workflows/ci.yml/badge.svg)](https://github.com/paulvollmer/go-dotbim/actions/workflows/ci.yml)

Go library for the [`.bim`](https://github.com/paireks/dotbim) file format. It builds triangulated meshes and reads and writes them as JSON at schema `1.0.0`.

Coordinates are meters. The origin of a shape is its minimum corner. X is width, Y is depth, and Z is up.

## Install

```bash
go get github.com/paulvollmer/go-dotbim
```

The module requires Go 1.27.2.

## Usage

A `.bim` file is a `DotBIM` value: meshes, elements that place those meshes, and a string map of file info. `encoding/json` marshals and unmarshals the struct.

```go
package main

import (
	"encoding/json"
	"os"

	"uuid"

	"github.com/paulvollmer/go-dotbim"
	"github.com/paulvollmer/go-dotbim/geometry/common/wall"
)

func main() {
	w, err := wall.New(4, 2.5, 0.2, nil)
	if err != nil {
		panic(err)
	}
	mesh, err := w.Mesh()
	if err != nil {
		panic(err)
	}
	mesh.MeshID = 0

	file := dotbim.NewDotBIM(map[string]string{"Author": "example"})
	file.AddMesh(*mesh)
	file.AddElement(*dotbim.NewElement(
		mesh.MeshID,
		*dotbim.NewVector(0, 0, 0),
		*dotbim.NewRotation(0, 0, 0, 1),
		uuid.New(),
		w.Type(),
		*dotbim.NewColor(230, 225, 210, 255),
		w.Info(),
	))

	data, err := json.MarshalIndent(file, "", "  ")
	if err != nil {
		panic(err)
	}
	if err := os.WriteFile("wall.bim", data, 0o644); err != nil {
		panic(err)
	}
}
```

`NewRotation(0, 0, 0, 1)` is the identity rotation. Constructors in `geometry` return a mesh with id 0. Set `MeshID` before `AddMesh`. `units` converts other lengths to meters before they become coordinates.

`Mesh`, `Element`, and `DotBIM` also have builders generated by [go-genbuilder](https://github.com/paulvollmer/go-genbuilder).

## Geometry

`geometry/primitive` builds meshes and returns a `*Mesh` with mesh id 0. Every size must be greater than zero.

| Function | Shape |
| --- | --- |
| `Box` | Rectangular box |
| `Wedge` | Ramp, full height at `y = 0` |
| `Cylinder` | Cylinder along Z. `capped` adds the discs |
| `Cone` | Cone along Z. `capped` adds the base |
| `Sphere` | Latitude-longitude sphere |
| `Extrude` | Vertical solid from a counter-clockwise profile, with optional rectangular holes |

`geometry/common` builds building elements on top of those meshes. Each value reports its element type and a dimension map through `Type` and `Info`.

| Package | Axes |
| --- | --- |
| `wall` | Length along Y, thickness along X, height along Z. An opening is optional and must sit inside the face. |
| `slab` | Width along X, depth along Y, thickness along Z |
| `roof` | Single slope. Full rise at `y = 0`, zero at `y = depth` |
| `door` | Width along Y, thickness along X, height along Z |
| `window` | Same axes as a door. `Meshes` returns the frame and the glass |
| `beam` | Width along X, length along Y, depth along Z |
| `column` | `New` is rectangular. `NewCircular` is a capped cylinder centered on `(radius, radius)` |
| `stair` | Straight flight. Length along Y, width along X, height along Z |

## Development

```bash
make test   # go test ./...
make build  # build every example
make fmt    # go fmt ./...
make gen    # regenerate the builders
```

Files ending in `_gen.go` are generated. Run `make gen` after changing a type marked with `go:generate`.
